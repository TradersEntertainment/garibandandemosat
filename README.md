# garibandan.com — Halkın Akıllı Fiyat Karşılaştırma Motoru 🏷️💸

> *"Aynı ürüne fazla para vermek zenginlerin işi. Garibandan.com en dip fiyatı bulur."*

Türkiye'nin en popüler pazar yerlerini (Trendyol, Hepsiburada, Amazon TR, Teknosa, MediaMarkt, N11, Pazarama) ve 4 büyük süpermarketini (Migros, CarrefourSA, ŞOK, A101) canlı kıyaslayan, reklam almayan, sahte indirimleri afişe eden yeni nesil akıllı fiyat arama motoru.

## 🚀 Özellikler

- **0 Reklam, %100 Şeffaflık:** Komisyon verenin değil, gerçekten en ucuz mağazanın en üstte yer aldığı bağımsız sıralama.
- **İnteraktif Fiyat Geçmişi:** Son 6 aylık fiyat grafiği (1 Ay, 3 Ay, 6 Ay, 1 Yıl) ve fiyat dalgalanması analizi.
- **Fiyat Şişirme Dedektörü:** İndirim öncesi fiyatı katlayıp sahte indirim yapan satıcıları afişe eden algoritma.
- **Gariban Market Sepeti:** 4 süpermarket arasında temel gıda sepetinizi kıyaslayıp en kârlı marketi veya parçalı sipariş formülünü bulur.
- **Günün Kelepirleri:** Son 6 ayın dip fiyatına inen ürünlerde geri sayımlı fırsat radarı.
- **Kupon & İndirim Kodu Avcısı:** Amazon, Trendyol, Hepsiburada için tek tıkla kopyalanabilen aktif kuponlar.
- **Fiyat Alarmı Radarı:** Hedef fiyat belirleyip fiyat düşünce bildirim alma.

## 🛠️ Teknoloji Yığını

- **React 19 & TypeScript**
- **Vite**
- **Tailwind CSS v3**
- **Lucide Icons**
- **Canvas Confetti**

## 💻 Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Canlı dağıtım derlemesi (Production Build)
npm run build
```
